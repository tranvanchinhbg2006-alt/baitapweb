BÀI TẬP ASP.NET RAZOR PAGES

1. Mở file VnEGoRazorPages.csproj bằng Visual Studio.
2. Nếu Visual Studio hỏi restore package thì chọn Restore.
3. Nhấn Ctrl + F5 hoặc nút Run để chạy.
4. Giao diện chính nằm ở Pages/Index.cshtml.
5. CSS nằm ở wwwroot/css/site.css.
6. Ảnh giao diện nằm ở wwwroot/images/.

Đây là giao diện tĩnh theo ảnh đề bài, chưa có chức năng đăng nhập,
cơ sở dữ liệu hay xử lý dữ liệu động.
